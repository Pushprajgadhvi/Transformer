Step-by-Step Mechanics
  • 1

    Tokenise Input

    Split sentence into tokens; each gets an embedding vector of size d_model.

  • 2

    Linear Projections → Q, K, V

    Multiply embeddings by learned W_Q, W_K, W_V weight matrices.

  • 3

    Scaled Dot-Product Scores

    Compute QKᵀ / √d_k. Scale prevents vanishing gradients in softmax.

  • 4

    Softmax → Attention Weights

    Convert scores to probabilities. Each row sums to 1. Temperature controls sharpness.

  • 5

    Weighted Sum of Values → Output

    Output = Attention_Weights × V. Each token gets a context-aware representation.

Core Formula
Attention(Q, K, V) = softmax(QKᵀ / √d_k) · V
Q (Query) — What am I looking for?
K (Key) — What do I have?
V (Value) — What do I return?
√d_k — Temperature scaling
